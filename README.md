# Posturología clínica · Bilbao 2026

Web de estudio con las diapositivas del curso de Posturología clínica (Bilbao 2026, Ruth Delgado), organizadas por temas en pestañas y pensada para el móvil.

- Todo está en un único archivo: `index.html`. Funciona también descargado y sin conexión.
- Acceso con una contraseña sencilla (protección básica: el contenido sigue dentro del archivo).
- Necesita abrirse en un navegador; la vista previa sin JavaScript (Archivos/WhatsApp del iPhone) solo muestra un aviso.
- En un navegador además hay buscador, marcas de «estudiada» y visor a pantalla completa.

Se publica automáticamente en GitHub Pages con cada `push` a `main`.
